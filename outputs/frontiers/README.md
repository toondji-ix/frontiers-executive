# Frontiers Executive Institute

Buildless HTML/CSS/JavaScript implementation of Figma node 288:1268.

Additional pages: `about.html` (288:1818), `services.html` (288:2212), and `contact.html` (288:2897, enclosing the supplied navigation node 288:2902). Shared navigation connects all four pages. Services enquiry links preselect the chosen programme on Contact. The form validates name and email, then prepares an email draft; no submission backend is configured and no message is automatically sent.

Serve `dist/` with any static HTTP server. No package installation or build is required.

Programme enquiries open an email draft to the address supplied in Figma. No email is sent automatically. Navigation uses page sections; mobile navigation supports keyboard and Escape. The supplied phone, address, testimonials, partner names and statistics are reproduced from the design and require owner verification before public release. No social account URLs were provided, so inactive social links have not been fabricated.

Design adjustments: white text on red buttons, brighter red on dark surfaces, readable secondary copy, responsive grids, mobile navigation, visible focus and semantic links. Programme duration, delivery formats and pricing have not been invented.
